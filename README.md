# الموقع الشخصي ومعرض الأعمال التفاعلي — علي حسن (Ali Hassan)
## Professional Portfolio & Interactive Showcase with Full Personal CMS

منصة شخصية متكاملة واحترافية مبنية بأحدث معايير الويب باستخدام **Next.js 14 (App Router)**، **TypeScript**، و **Tailwind CSS**. تدعم اللغتين العربية (RTL) والإنجليزية (LTR)، والوضعين الداكن والفاتح (Dark/Light Mode)، ومزودة بـ **لوحة تحكم خاصة كاملة (`/admin`)** للتحكم في كافة محتويات الموقع دون الحاجة لتعديل الكود.

---

### 🌟 المحاور والمجالات الأساسية في الموقع
1. **الإلكترونيات وهندسة السيارات (Electronics & Automotive Systems)**:
   - طالب بالفرقة الرابعة - قسم الإلكترونيات بالكلية المصرية الكورية للتكنولوجيا الصناعية والطاقة.
   - تشخيص أعطال السيارات، وحدات التحكم (ECU)، وبروتوكول OBD-II و CAN-Bus.
   - النمذجة ثلاثية الأبعاد ببرنامج SOLIDWORKS.
   - تدريبات ميدانية عملية معتمدة (مركز خدمة نيسان، ومركز مصر حلوان للسيارات MHA).

2. **المونتاج وصناعة المحتوى وتدريج الألوان (Video Editing & Color Grading)**:
   - مونتير فيديو ومصحح ألوان سينمائي محترف ببرنامج **DaVinci Resolve Studio & DaVinci Fusion**.
   - ضبط تباين الألوان الاحترافي، سير عمل ACES، مؤثرات بصرية VFX، وميكساج الصوت في Fairlight.
   - مشغل فيديو مدمج داخل الموقع لمشاهدة أعمال المونتاج مباشرة.

3. **تطوير المواقع والتطبيقات السحابية (Web & AI Applications)**:
   - هندسة وتطوير منصات ويب سريعة وذكية مثل **منصة [Medicology](https://medicology-eg.vercel.app) الطبية**.
   - تقنيات الـ Fullstack، الـ RESTful APIs، وتطبيقات الذكاء الاصطناعي.

### 🚀 كيفية تشغيل المشروع

المشروع موجود في المجلد:
`C:\Users\TARGET\.gemini\antigravity\scratch\ali-hassan-portfolio`

#### التشغيل في بيئة التطوير (Development):
```bash
cd C:\Users\TARGET\.gemini\antigravity\scratch\ali-hassan-portfolio
pnpm dev
# أو
npm run dev
```

#### التشغيل في بيئة الإنتاج السريعة (Production):
```bash
pnpm build
pnpm start -p 3000
```
- رابط الموقع الرئيسي: **http://localhost:3000**
- رابط لوحة التحكم الشخصية: **http://localhost:3000/admin**

### 🔐 لوحة التحكم الخاصة (`/admin` — Full Personal CMS)
- **كلمة المرور الافتراضية**: `admin` (يمكنك تغييرها بسهولة من داخل لوحة التحكم تحت تبويب البيانات الشخصية).
- **أقسام لوحة التحكم**:
  1. **البيانات الشخصية و الـ CV**: تعديل الاسم، النبذة، المسمى المهني، البريد الرسمي (`alihassanofficial911@gmail.com`)، رقم الواتساب، رفع صورة شخصية جديدة، ورفع ملف السيرة الذاتية (CV PDF).
  2. **إدارة المشاريع والأعمال (Projects Manager)**: إضافة مشاريع جديدة، تعديل بياناتها، تحديد تصنيفها (فيديو DaVinci / إلكترونيات وسيارات / ويب)، ورفع صور أو روابط فيديوهات YouTube لتشغيلها مباشرة في المعرض.
  3. **التعليم والتدريب الميداني (Experience & Internships)**: إضافة أي مركز أو شركة تدربت أو عملت بها (نيسان، مصر حلوان، الكلية المصرية الكورية، فريلانس) مع تفاصيل المهام وشهادات التدريب.
  4. **المهارات والشهادات (Skills & Certificates)**: ضبط نسب الإتقان لكل مهارة، إضافة مهارات جديدة، وإضافة شهادات معتمدة مع صورها وروابط التحقق.
  5. **رسائل الزوار (Messages Inbox)**: قراءة وحذف الرسائل الواردة من نموذج التواصل في الصفحة الرئيسية.
  6. **النسخ الاحتياطي (JSON Backup & Supabase)**: تنزيل نسخة كاملة من قاعدة بيانات الموقع بضغطة زر.

### 💾 قاعدة البيانات وجاهزية الربط بـ Supabase
- البيانات محفوظة تلقائياً ومحلياً في: `data/portfolio-db.json`
- أي تعديل من لوحة التحكم ينعكس في الصفحة الرئيسية فوراً.
- هيكل البيانات متوافق مع نظام الجداول العلائقية (Relational Database) لربطه بـ Supabase في أي وقت عبر وضع مفاتيح المشروع في `.env.local`.
